# personal-portfolio-website

A resonsive personal portfolio website developed using HTML, CSS, and JavaScript to showcase my skills, projects, professional experience, education background, and contact details.

## Features
* Responsive layouts for Mobile, Tablet, and Laptop devices.
* Professional home page with resume download functionality.
* About section with introduction and education details.
* Skills section highlighting technical expertise, tools, and technologies.
* Project showcase.
* Professional industry experience.
* Contact details and social media links.
* Mobile friendly navigation menu.

## Technologies Used

* HTML5
* CSS3
* JavaScript
